GitHub Releases에서 운영체제에 맞는 압축 파일을 내려받아 실행합니다. v2.0.13은 Windows x64·macOS Apple Silicon GUI와 Linux x86_64 CLI를 제공합니다.

Releases 열기 GitHub 저장소
mac

macOS Apple Silicon

릴리즈 페이지에서 ClipCatcher-macOS.zip 파일을 내려받아 압축을 풀고 실행합니다. Intel Mac 전용 빌드는 없습니다. ad-hoc 서명만 적용되며 Apple 공증은 포함하지 않습니다.

win

Windows x64

ClipCatcher-Windows.zip을 풀고 ClipCatcher.exe를 실행합니다. 앱은 코드 서명되지 않았습니다.

cli

Linux x86_64 CLI

ClipCatcher-Linux-x86_64.tar.gz를 풀고 ./clipcatcher --cli check로 확인합니다. glibc 2.35 이상이 필요하며 GUI는 포함하지 않습니다.

Before Download

무결성·이용 범위 안내

릴리스의 SHA256SUMS로 다운로드 파일의 무결성을 확인하세요. FFmpeg와 yt-dlp는 패키지에 포함되며 FFprobe는 포함되지 않습니다. 자세한 도구·라이선스 정보는 패키지의 third-party-notices를 참고하세요.

패키지 검사 통과가 모든 영상·네트워크에서의 다운로드 성공을 보장하지는 않습니다. 로그인·성인 인증·회원 전용 콘텐츠는 CLI 지원 범위 밖이며 접속 제한을 우회하지 않습니다.

저작권 안내

ClipCatcher는 사용자가 접근 가능한 영상의 저장을 돕는 도구입니다. 프로그램 사용과 다운로드는 자유롭게 할 수 있지만, 영상과 음성 등 콘텐츠의 저작권은 원 저작권자에게 있습니다. 개인 보관 범위를 넘어 재업로드, 공유, 편집물 공개, 상업적 이용을 할 때는 각 플랫폼의 이용약관과 원 저작권자의 허락 범위를 반드시 확인해주세요.

소스에서 실행

git clone https://github.com/ThankyouJerry/ClipCatcher.git
cd ClipCatcher
pip install -r requirements.txt
python src/main.py

Cloud CLI

Linux·클라우드에서 사용

패키지는 ./clipcatcher --cli, 소스는 python src/main.py --cli 뒤에 check, info, download 명령을 사용합니다. 시간 범위를 생략하면 전체 영상이 다운로드됩니다.

CHZZK API/HLS는 기존 HTTPS 프록시·NO_PROXY 설정을 따릅니다. 프록시를 새로 구성하거나 .netrc 인증을 자동으로 읽지 않으며 HTTPS 검증과 쿠키 전달 제한을 유지합니다.

명령·시간 범위 예시 · Linux 패키지 상세 안내

다운로드가 실패하면 필수 도구 설치 안내와 실패 탭의 오류 메시지를 먼저 확인하세요.
